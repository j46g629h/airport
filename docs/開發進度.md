**v0.2 的六項調整（2026-09-02）**

| # | 調整 | 做法 |
|---|---|---|
| 1 | 電腦上日期欄顯示 mm/dd/yyyy | `<input type="date">` 的顯示順序管不了（跟著裝置地區設定）。**輸入框下方加一行我們控制的 `→ 18/09/2026`**。送出的值本來就是 `YYYY-MM-DD`，查詢結果一直是對的 |
| 2 | email 不用打完整 | 改成部分比對，**最少 3 個字**（前後端都擋） |
| 3 | 只顯示未完成的 | 改成**航班日期 ≥ 今天**（含今天）。不用 STATUS 判斷——狀態靠人維護，一定會有人忘記改 |
| 4 | 印尼文用詞 | `Tanggal Pesawat` / `NO Pesawat` |
| 5 | 返回鍵移到左上角 | 做成有邊框的按鈕（純文字在手機上不像可以點），高度 48px。窄螢幕時標題讓位 |
| 6 | 頁尾比照 KANTIN | 維護單位 · 分機 · 版本 ＋ 管理者登入小連結。分機留空就不顯示（`js/config.js` 的 `SYSTEM_INFO.contact`）|

順帶修掉：印尼文句子裡的全形冒號（`Dikelola oleh：` → `Dikelola oleh: `），改用 `colon()` 跟著語言走。
